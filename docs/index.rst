Submission Checker
==================

CLI tool for validating MLPerf benchmark submissions.

.. toctree::
   :maxdepth: 2
   :caption: Contents:

   api

Quickstart
----------

Install::

   pip install endpoints-submission-cli

Run against a submission directory::

   endpoints-submission-cli check-submission /path/to/submission
